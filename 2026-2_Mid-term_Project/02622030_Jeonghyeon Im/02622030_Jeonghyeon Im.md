## 1. Problem — 해결하려는 문제

qRT-PCR 실험 결과를 분석할 때 연구자는 Excel 원본 파일에서 샘플별·유전자별 Ct 값을 분류하고, 기술적 반복 측정값을 확인한 뒤 평균 Ct, ΔCt, ΔΔCt 및 상대 유전자 발현량(2^−ΔΔCt)을 계산한다. 이 과정을 수작업으로 수행하면 시간이 오래 걸리고, 샘플 혼동이나 수식 참조 오류가 발생할 수 있다.

이 프로젝트의 목표는 **qRT-PCR 원본 Excel 파일에서 상대 유전자 발현량 결과와 그래프를 자동 생성하고, 계산 전 데이터 오류를 발견하는 연구 보조 웹앱**을 만드는 것이다.

## 2. Users — 사용자

- **주요 사용자:** qRT-PCR 실험을 수행하는 생명과학 대학원생과 연구자
- **사용 환경:** 프로그래밍 지식 없이 브라우저에서 Excel 파일을 업로드하고 분석 조건을 선택
- **기대 효과:** 반복적인 Excel 작업 감소, 계산 과정의 일관성 향상, 데이터 오류 조기 발견

## 3. Features — 핵심 기능

1. **데이터 업로드:** qRT-PCR 장비에서 내보낸 Excel(.xlsx) 파일을 읽고 `Sample Name`, `Target Name`, `CT` 열을 인식한다. 예제 파일은 `Results` 시트에 측정값이 있다.
2. **자동 그룹화 및 검증:** 샘플명과 유전자명을 기준으로 Ct 값을 묶고, 사용자가 지정한 기술적 반복 횟수(3회 또는 4회)와 실제 데이터가 일치하는지 검사한다. 누락된 Ct나 잘못된 그룹에 경고를 표시한다.
3. **상대 발현량 계산:** 사용자가 기준 유전자(reference gene)와 대조군(control sample)을 선택하면 평균 Ct, Ct 표준편차, ΔCt, ΔΔCt, 상대 발현량을 계산한다.
   - ΔCt = Mean Ct(target) − Mean Ct(reference)
   - ΔΔCt = ΔCt(sample) − ΔCt(control)
   - Relative expression = 2^(−ΔΔCt)
4. **시각화 및 저장:** 결과표와 유전자별 상대 발현량 그래프를 보여주고, 분석 결과 Excel 및 그래프 이미지 파일을 내려받을 수 있다.
5. **검증 가능한 수치 처리:** AI가 Ct 값이나 분석 결과를 생성하지 않는다. 수치 계산은 Python 코드가 담당하며, 연구자는 기준 유전자와 대조군 선정 및 결과 해석을 책임진다.

## 4. Interaction Flow — 사용 흐름과 실패 상황

### 정상 사용 흐름

1. 사용자가 Streamlit 앱을 실행하고 qRT-PCR Excel 파일을 업로드한다.
2. 앱이 데이터 구조를 읽어 샘플·유전자별 측정값을 표시한다.
3. 사용자가 기술적 반복 횟수(3 또는 4)를 선택한다.
4. 앱이 그룹별 측정 개수와 Ct 유효성을 검사하고 검증 결과를 보여준다.
5. 사용자가 기준 유전자와 대조군 샘플을 선택한다.
6. 앱이 ΔCt, ΔΔCt, 2^(−ΔΔCt)을 계산해 표와 그래프로 표시한다.
7. 사용자가 결과 파일과 그래프를 다운로드한다.

### 실패 상황(Failure States)과 처리 방식

| 실패 상황 | 기대되는 앱 동작 |
| --- | --- |
| Excel 형식이 다르거나 필수 열이 없는 경우 | 파일을 분석할 수 없음을 알리고 필요한 열을 안내한다. |
| Ct가 비어 있거나 숫자가 아닌 경우 | 해당 측정값·그룹의 문제를 알리고 부적절한 값을 정상 결과처럼 사용하지 않는다. |
| 기술적 반복 수가 설정과 다른 경우 | 그룹별 반복 횟수 불일치를 경고하고 유효하지 않은 그룹을 구분한다. |
| 선택한 기준 유전자 또는 대조군 데이터가 부족한 경우 | 정상적인 ΔCt/ΔΔCt 계산이 불가능한 조건을 표시한다. |
| 실행 환경의 패키지가 없거나 호환되지 않는 경우 | `requirements.txt`로 의존성을 설치하고 `README.md`의 실행 절차에 따라 재실행한다. |

## 5. Success Criteria — 성공 기준과 확인 결과

- **파일 인식:** 예제 qRT-PCR 데이터의 96개 Ct 측정값을 읽고, 8개 샘플 × 4개 유전자 = 32개 그룹으로 분류한다.
- **반복 수 검증:** 3회 반복으로 설정하면 예제의 32개 그룹이 정상적으로 검증된다. 4회 반복으로 설정하면 32개 그룹 모두에서 반복 수 불일치가 표시된다.
- **계산 검증:** 평균 Ct, ΔCt, ΔΔCt, 상대 발현량을 독립적인 계산 결과와 비교해 일치 여부를 확인한다.
- **시연 가능성:** 브라우저에서 Excel 업로드, 조건 설정, 결과표·그래프 표시, 다운로드 과정을 실행한다.
- **자동 테스트:** 최종 개발 과정에서 `pytest` 자동 테스트 14개가 통과했다.

### AI Agent 활용과 범위

연구자가 분석 목적, 원본 데이터 구조, 계산 방법, 검증 조건을 정의하고 Antigravity AI Agent를 활용해 Python/Streamlit 앱의 코드를 작성·수정했다. 실행 환경과 데이터 표시 문제를 해결하는 과정에서도 AI Agent를 사용했다. AI는 구현을 보조했지만, 계산 정확성과 과학적 해석은 연구자가 확인해야 한다.

### 현재 한계

현재는 특정 장비의 Excel 출력 형식을 중심으로 구현되어 있으며, **기술적 반복(technical replicate)**에 대한 처리 결과를 독립적인 **생물학적 반복(biological replicate)**의 통계적 유의성으로 해석해서는 안 된다. 향후 다양한 장비 파일 인식과 생물학적 반복별 통계 분석을 확장할 수 있다.
