# FinMentor – AI-Powered Financial Learning Assistant

## 1. Motivation
Financial markets are accessible to everyone, but beginners often lack proper understanding. Poor decisions can lead to losses and confusion.  
**Goal:** Make financial learning simple, interactive, and practical.

## 2. Problem
- Users invest without understanding the market  
- Tools provide data but not explanations  
- Learning and trading resources are disconnected  

## 3. Proposed Solution
FinMentor is an AI-powered assistant that:
- Simplifies financial learning  
- Supports decision-making  
- Combines real-time data, AI explanations, and simulation  

### System Overview
```
User → Interface → AI + Data → Insights → User
```

## 4. Core Features

### 4.1 Market Analysis
- Real-time stock and crypto data  
- AI explains trends  
- Reduces confusion  

```
Market Data → AI → Explanation → User
```

### 4.2 News Analysis
- Summarizes financial news  
- Detects sentiment  
- Shows market impact  

```
News → AI → Summary + Sentiment → User
```

### 4.3 Portfolio Analysis
- Tracks investments  
- Identifies risks  
- Links relevant news  

```
Portfolio → AI → Risk + Insights → User
```

### 4.4 Interactive Learning
- Chat-based learning  
- Step-by-step explanations  
- Quiz for understanding  

```
User → Chat → AI → Explanation + Quiz
```

### 4.5 Roleplay Scenarios
- Simulates real-world situations  
- Trains decision-making  
- Handles high-risk scenarios  

```
Scenario → User Decision → AI → Feedback
```

## 5. Implementation
- Streamlit web application  
- Real-time data via yfinance API  
- Plotly for visualization  
- AI using Ollama + Qwen  

### Architecture
```
User → UI → Modules (Market | News | Portfolio | Learning)
Modules → AI → Output
```

## 6. Conclusion
FinMentor:
- Makes financial learning interactive  
- Improves decision-making  
- Bridges gap between data and understanding
